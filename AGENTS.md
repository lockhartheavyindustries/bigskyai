## GitHub agent coordination

Before mutable work, read `.coordination/project.json`,
`.coordination/lifecycle.md`, this file, and the repository briefing. Search
open issues and pull requests for overlap; create or accept an issue; work from
an isolated branch or linked worktree; and use a linked pull request for review.

Keep lifecycle state in labels and dated comments. Before pausing, leave a
continuation-ready handoff headed with the acting agent and platform. The private
`lockhartheavyindustries/agent-coordination` hub adds shared protocol and
cross-repository details when reachable.

This coordination contract does not replace project authority or authorize
manual deployment, environment, account, billing, domain, credential,
protection, or other external changes. Those actions require separately scoped
owner approval.
